    ■ under the hood
    
          
    Short enough to read over coffee.
    
          
    The contract is about eighty lines. It keeps a list of products per wallet and a list of changes per product, and it only ever adds to them.
    
          
    
            
    2functions that write
    
            
    4reasons for a change
    
            
    0admin keys or owners
    
            
    0tokens, fees or payments

    struct Change {
  int32  delta;     // +12 or −3
  uint32 qtyAfter;  // 42
  uint8  reason;    // 0 Restock … 3 Correction
  uint64 at;        // block time
}

function adjustStock(id, delta, reason) {
  // your own product only
  if (qty + delta < 0) revert BelowZero();
  history[msg.sender][id].push(…);
  // there is no pop, no edit, no delete
}

    The rules, and the answers.
    
          
      
            
    • One wallet, one stockroom. Only that wallet can add products or change stock.
      • 
            
    • Stock can't go below zero. The app checks before sending and the contract refuses anyway.
      • 
            
    • History is append-only. Each change stores the delta, the quantity after, a reason and the block time. There is no edit and no delete.
      • 
            
    • Nothing else. No tokens, no payments, no admin keys, no personal data.
      • 
          
    
        
    
        
    
          
    
            Why put inventory on-chain?
            
    A spreadsheet can be changed after the fact and nobody would know. Here every restock, sale or correction is a BOT Chain transaction with its own timestamp, so the history only grows. A mistake is fixed by adding a correction, not by rewriting the past.
    
          
    
          
    
            Who can see my stock?
            
    Everyone. Data on BOT Chain is public, and anyone with your wallet address can open your read-only stockroom. Use demo products or things you're happy to show, and keep personal details out of product names.
    
          
    
          
    
            Who can change it?
            
    Only the wallet that owns the stockroom. The contract writes to the sender's own list, so there is no way to touch someone else's products.
    
          
    
          
    
            Can I undo or delete a change?
            
    No. Add a new change with the reason "Correction" instead. Both lines stay in the history.
    
          
    
          
    
            What does it cost?
            
    The app is free and takes no payments. Each change is one transaction, so you pay the BOT Chain network fee in BOT. Viewing is free.
